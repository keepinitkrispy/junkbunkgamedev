# The Junk Bunch Adventures — Art Style Guide

## Core Identity

**"90s Nickelodeon meets Pixar"**

Think Rugrats, Aaahh!!! Real Monsters, Rocko's Modern Life — but with the
roundness, warmth and expressiveness of early Pixar (Monsters Inc., A Bug's Life).
Ugly-cute. Loud. Wobbly. Full of personality. Every character looks like it was
drawn by a kid who had way too much sugar.

---

## Color Philosophy

### Rules
- **Always oversaturate.** If it looks almost too bright, it's correct.
- **No pastels. No muted tones. No gradients.**
- **Black outlines only** — thick (2px at game resolution), slightly wobbly
- **Flat fills** — 3 to 5 colors per character max (base, shadow, highlight, accent)
- **Shadow = darker + slightly more saturated**, never grey or black

### Nickelodeon Palette Inspiration
| Feeling | Color |
|---|---|
| Energy | `#FF6B00` Nickelodeon Orange |
| Gross/Fun | `#7BC67E` Slime Green |
| Danger | `#FF2D55` Hot Pink-Red |
| Weird | `#9B59B6` Electric Purple |
| Highlight | `#FFE600` Cartoon Yellow |
| Sky/Cool | `#00B4FF` Sky Blue |

Every world has its own palette but always hits this level of saturation.

## Character Design Rules

### Shape Language (Nickelodeon DNA)
- **Heroes (Bunch members):** Round, lumpy, asymmetrical — no perfect circles
- **Enemies:** Sharper, more angular, but still exaggerated and silly
- **Bosses:** Huge, imposing, but always slightly goofy — never truly scary

### Proportions
- **Giant heads** — at least 40% of total character height
- **Tiny limbs** — stubby arms, stubby legs
- **Huge eyes** — expressive, slightly mismatched (very Nickelodeon)
- **Mouth always showing emotion** — open, grinning, grimacing, never neutral

### Outlines
- 2px black outline at game resolution
- Slightly uneven / hand-drawn feel — not perfectly smooth
- Inner details use dark color lines, not black

### Animation Style
- **Squash and stretch** — exaggerated, rubbery (Pixar influence)
- **Hold on 2s** — each frame held 2 ticks for that choppy cartoon feel
- **Anticipation frames** — big windup before attacks
- **Death animations** — silly, not violent (spin out, deflate, pop)

## Sprite Specs

| Element | Size |
|---|---|
| Bunch members | 24×24 px |
| Standard enemies | 16×16 px |
| Large enemies | 24×24 px |
| Boss sprites | 48×48 px |
| Lane tiles | 16×16 px |
| UI icons | 16×16 px |

Game renders at **320×180** upscaled — keep everything crisp, no anti-aliasing.

---

## UI Style

- **Font:** Chunky, rounded, hand-drawn style (think Nickelodeon credits font)
- **Buttons:** Thick black border, bright fill, slight drop shadow in a darker shade
- **HUD:** Minimal — scrap counter top-left, lives top-right, wave indicator top-center
- **Scrap icon:** A little glowing bolt of junk lightning ⚡
- **Lives icon:** A tiny Junk Bunch heart (stitched together, asymmetrical)

## What NOT to Do

- No anime influence
- No realistic shading or lighting
- No thin outlines
- No muted / desaturated colors
- No perfectly symmetrical characters
- No clean, corporate-looking UI
